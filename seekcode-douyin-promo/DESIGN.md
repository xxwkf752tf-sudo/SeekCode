# SeekCode 抖音宣传片视觉规范

## 风格定位
- 技术冷静感（technical / calm），配合 SeekCode 终端助手的效率定位
- 暗色背景，代码/终端氛围，抖音夜间观看友好
- 动效精确、克制，以文字和 UI 元素为主，避免过度装饰

## 色彩
- 背景主色：`#121211`（接近纯黑，略带暖调）
- 背景次色：`#1e1e1d`（卡片/面板）
- 品牌主色：`#c96442`（赤陶橙，用于强调、按钮、光效）
- 品牌高亮：`#d97757`（悬停/高亮状态）
- 文字主色：`#f1f1ef`（标题、正文）
- 文字次色：`#b7b5a9`（辅助说明）
- 成功色：`#788c5d`（状态指示）
- 终端绿：`#a8c5a8`（代码片段、光标）

## 字体
- 标题/UI：`Poppins`, "Microsoft YaHei", sans-serif
- 阅读/衬线：`Lora`, "Noto Serif SC", serif（品牌名使用）
- 等宽代码：`Geist Mono`, "SF Mono", Consolas, monospace

## 抖音合规导流
- 不直接展示完整 URL，不朗读链接
- 使用平台搜索提示："在 GitHub / Gitee 搜索 SeekCode"
- 使用分块视觉暗示：GitHub/Gitee 图标 + "SeekCode" 文字，避免组成可点击链接
- 片尾提示："主页置顶 / 评论区见"

## 反模式
- 不出现二维码、完整超链接、可点击按钮样式
- 不使用高饱和渐变铺满屏幕
- 不使用超过 3 种主色
- 不显示真实 API Key 或敏感配置信息
