## 二、产品概述

SeekCode 是一款 **Windows 桌面端 AI 终端助手**。用户用自然语言描述任务，AI 通过 DeepSeek 大模型生成并执行终端命令，完成编程、文件操作、系统维护等任务。项目开源，采用 MIT 协议。

核心标语：用自然语言指挥你的电脑。

---

## 三、核心功能

- **自然语言驱动任务**：用大白话描述需求（例如"帮我把桌面所有 PNG 压缩到 80% 质量放到 D:\backup"），AI 拆解步骤并调用终端命令执行。
- **双模型自动切换**：集成 DeepSeek V4 Pro（强能力）与 V4 Flash（快速经济）。自动模式下先判定任务复杂度，简单 / 中等任务用 Flash，复杂任务自动切换到 Pro。
- **三级权限控制**：
  - 对话模式：只能聊天，不执行任何命令。
  - 标准模式：可执行命令，但删除、批量文件等高危操作需要二次确认。
  - 完全访问模式：允许 AI 自动执行命令，但删除类操作会先压缩备份，且单次最多处理 1000 个文件。
- **本地优先，密钥不落地仓库**：API Key 仅保存在本地 `%APPDATA%\seekcode\config.json`，使用 Windows DPAPI 加密，输入框为密码圆点 + 显示/隐藏切换，可随时删除，**不会上传任何第三方服务器**。
- **对话管理**：左侧可折叠面板支持新建、加载、导出历史会话。

## 四、技术架构（仓库结构）

- **后端**：Python + FastAPI，位于 `backend/seekcode/`
  - `main.py`：服务入口
  - `server.py`：FastAPI 路由（配置、会话、消息、SSE 事件流、文件服务）
  - `agent.py`：AI 执行循环（思考 → 命令 → 执行 → 回传 → 再思考，直到 done）
  - `executor.py`：命令执行器（调用系统 shell，捕获 stdout/stderr/退出码）
  - `security.py`：权限与危险命令识别（rm / del / format / reg delete 等关键字）
  - `config.py`：配置与系统提示词管理
  - `api_client.py`：OpenAI 兼容的模型调用客户端（基于 httpx 异步流式）
  - `session.py` / `memory.py`：会话与本地记忆文件
- **前端**：纯 HTML / CSS / JS（`ui/`），**无框架、无构建步骤**，通过本地 Web 服务在浏览器中交互。
- **模型调用**：OpenAI 兼容的 `/chat/completions`，由 `api_client.py` 统一封装。
- **打包**：PyInstaller `--onefile` 生成单个 `SeekCode.exe`（约 17 MB），双击即运行，无需安装 Python 或任何依赖。

## 七、常见问题（FAQ）

**Q1：SeekCode 是免费的吗？**
A：SeekCode 本身完全免费且开源（MIT 协议）。使用时需自行准备 DeepSeek API Key，API 调用费用由 DeepSeek 按使用量收取，SeekCode 不额外加收任何费用。

**Q2：我的 API Key 安全吗？**
A：API Key 使用 Windows DPAPI 加密存储在本地配置文件中，绑定当前 Windows 用户账户；即使配置文件被复制到其他机器也无法解密。SeekCode 不会将你的 Key 发送到任何第三方服务器。

**Q3：支持 macOS 或 Linux 吗？**
A：目前 SeekCode 仅支持 Windows 10 / 11。这是因为核心功能依赖 Windows 命令行和 DPAPI 加密。后续版本计划支持 macOS 和 Linux，但需要重新设计命令执行与安全模块。

**Q4：完全访问模式安全吗？**
A：完全访问模式下 AI 可自动执行命令，但内置多重保护：删除操作先压缩备份到临时目录、单次最多处理 1000 个文件、所有操作写入审计日志。建议仅在可信环境和明确需求下开启。

**Q5：如何参与开源贡献？**
A：欢迎在 GitHub 上提交 Issue 报告 Bug 或提出功能建议。如果想贡献代码，请先在 Issue 中讨论想法，再提交 Pull Request，团队会认真审查每一个 PR。

**Q6：双模型自动切换是怎么工作的？**
A：自动模式下，系统先用 V4 Flash 对任务做复杂度判定（简单 / 中等 / 复杂）。简单和中等任务继续使用 Flash 以节省成本，复杂任务自动切换到 V4 Pro 以保证质量。也可关闭自动模式，手动指定模型。
