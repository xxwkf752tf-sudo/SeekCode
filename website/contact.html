在联系我们之前，先看看这里有没有你需要的答案。

SeekCode 本身完全免费且开源（MIT 协议）。使用时需要自行准备 DeepSeek API Key，API 调用费用由 DeepSeek 按使用量收取，SeekCode 不加收任何费用。

API Key 使用 Windows DPAPI 加密存储在本地配置文件中，绑定当前 Windows 用户账户。即使配置文件被复制到其他机器，也无法解密。SeekCode 不会将你的 Key 发送到任何第三方服务器。

目前 SeekCode 仅支持 Windows 10/11。这是因为核心功能依赖 Windows 命令行和 DPAPI 加密。后续版本计划支持 macOS 和 Linux，但需要重新设计命令执行和安全模块。

完全访问模式下，AI 可以自动执行命令，但我们内置了多重保护：删除操作会先压缩备份到临时目录，单次最多处理 1000 个文件，所有操作写入审计日志。建议仅在可信环境和明确需求下开启。

欢迎在 GitHub 上提交 Issue 报告 Bug 或提出功能建议。如果你想贡献代码，请先在 Issue 中讨论你的想法，然后提交 Pull Request。我们会认真审查每一个 PR。

自动模式下，系统会先用 V4 Flash 对任务做复杂度判定（简单/中等/复杂）。简单和中等任务继续使用 Flash 以节省成本，复杂任务自动切换到 V4 Pro 以保证质量。你也可以关闭自动模式，手动指定使用的模型。
