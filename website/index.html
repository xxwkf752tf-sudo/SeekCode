核心功能

为什么选择 SeekCode

从日常文件管理到复杂开发任务，SeekCode 让你用一句话完成过去需要十步的操作。

自然语言驱动

用大白话描述需求，AI 自动拆解步骤并调用终端命令执行。不需要记命令、不需要查文档。

双模型智能切换

集成 DeepSeek V4 Pro 与 V4 Flash。自动模式先判断任务复杂度，简单任务用 Flash 省成本，复杂任务用 Pro 保质量。

三级权限控制

对话模式只聊天不执行；标准模式高危操作需确认；完全访问模式自动执行但带安全备份。你始终掌控全局。

本地优先，隐私至上

API Key 通过 Windows DPAPI 加密存储，不上传任何第三方服务器。所有命令在你本机执行，数据不离开你的电脑。

循环执行直到完成

AI 不是执行一条命令就结束。它会根据终端输出继续决策，自动修正错误，循环执行直到任务真正完成。

对话记忆与上下文

内置记忆系统自动保存任务上下文、关键变量和中间结果。长任务不怕中断，随时可以恢复继续。

常见问题

SeekCode 是免费的吗？

SeekCode 完全免费且开源（MIT 协议）。使用时需自备 DeepSeek API Key，调用费用由 DeepSeek 按量收取。

我的 API Key 安全吗？

API Key 使用 Windows DPAPI 加密存储在本地，绑定当前用户账户，不会上传到任何第三方服务器。

支持 macOS 或 Linux 吗？

目前仅支持 Windows 10/11。后续版本计划支持 macOS 和 Linux，敬请期待。
