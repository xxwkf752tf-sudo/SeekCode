四大核心价值

SeekCode 不仅仅是一个命令行工具，它是一个理解你意图、自主决策、安全执行的 AI 伙伴。

理解意图

不是关键词匹配，而是真正的语义理解。描述模糊也没关系，AI 会追问澄清。

自主执行

AI 自己拆解步骤、生成命令、执行、检查结果、修正错误，循环直到完成。

安全可控

三级权限模式，危险操作必须确认，删除前自动备份。你始终拥有最终决定权。

隐私优先

API Key 本地 DPAPI 加密，命令在你机器上执行，数据不经过任何第三方服务器。

自然语言驱动任务

不需要记忆复杂的命令行语法，不需要查阅文档。只需用日常语言描述你想做的事，SeekCode 就能理解你的意图并自动执行。

三级权限控制

安全是 SeekCode 的核心设计原则。三种权限模式让你在不同场景下灵活控制 AI 的执行范围，危险操作永远不会偷偷执行。

  • 对话模式：纯聊天，不执行任何命令
  • 标准模式：可执行命令，高危操作需二次确认
  • 完全访问模式：自动执行，但删除前压缩备份，单次上限 1000 文件
  • 所有操作写入审计日志，可追溯

安全设计

多层安全保护

从密钥存储到命令执行，每一层都有安全机制保驾护航。

DPAPI 加密存储

API Key 使用 Windows DPAPI 加密，绑定当前用户账户，即使配置文件被复制也无法在其他机器上解密。

危险命令识别

内置危险命令识别引擎，对删除、格式化、注册表修改等高危操作自动拦截并要求二次确认。

删除前自动备份

完全访问模式下，删除类操作会先将文件压缩备份到临时目录，后续版本支持回收站还原。

执行超时保护

单条命令默认 60 秒超时，可自定义配置。遇到死循环或长时间运行的任务，随时点击停止按钮中断。

审计日志

所有命令执行记录写入审计日志，包括时间、命令内容、执行结果，方便事后追溯和排查。

数量上限保护

单次删除操作最多处理 1000 个文件，防止误操作导致大规模数据丢失。

常见问题

SeekCode 是免费的吗？

SeekCode 完全免费且开源（MIT 协议）。使用时需自备 DeepSeek API Key，调用费用由 DeepSeek 按量收取。

我的 API Key 安全吗？

API Key 使用 Windows DPAPI 加密存储在本地，绑定当前用户账户，不会上传到任何第三方服务器。

支持 macOS 或 Linux 吗？

目前仅支持 Windows 10/11。后续版本计划支持 macOS 和 Linux，敬请期待。
