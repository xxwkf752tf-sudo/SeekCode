让 AI 真正帮你做事

我们相信 AI 不应该只是聊天机器人。它应该理解你的意图，帮你执行任务，让你从重复劳动中解放出来。

我们的使命

每个人都有更重要的事要做，而不是在命令行里敲打 rm -rf 或者在五个文件夹之间来回切换。

SeekCode 诞生于一个简单的想法：如果 AI 能理解自然语言，为什么不能让它直接帮我们操作电脑？我们把 DeepSeek 大模型和 Windows 命令行连接起来，让 AI 不仅能说，还能做。从文件整理到环境配置，从批量处理到代码调试，用一句话完成过去需要十步的操作。

核心价值观

我们坚持的原则

这些原则指导着 SeekCode 的每一个功能设计和每一个技术决策。

安全第一

AI 可以帮你做事，但不能替你做决定。危险操作必须经过你的确认，数据安全永远是底线。

隐私至上

你的数据属于你。所有操作在本地执行，密钥本地加密，不向任何第三方服务器发送你的信息。

极简体验

双击启动，即开即用。不需要配置环境，不需要学习命令行，两分钟内开始第一次体验。

开源透明

基于 MIT 协议开源，代码完全公开。你可以审查每一行代码，也可以参与改进。

发展历程

我们的故事

2025 年 12 月

想法萌芽

团队在使用各类 AI 助手时发现，市面上的产品大多只能聊天，不能真正帮你执行任务。我们决定做一个能"动手"的 AI 助手。

2026 年 3 月

项目启动

确定技术路线：Python + FastAPI 后端，纯前端界面，接入 DeepSeek V4 双模型。开始核心架构设计和原型开发。

2026 年 6 月

第一阶段完成

完成前后端原型，支持自然语言对话、命令执行、三级权限控制、配置持久化与一键启动。开始内测。

2026 年 8 月

正式发布

SeekCode v1.0 正式开源发布。支持 Windows 10/11，双模型自动切换，完整安全机制。启动第二阶段开发。

常见问题

SeekCode 是免费的吗？

SeekCode 完全免费且开源（MIT 协议）。使用时需自备 DeepSeek API Key，调用费用由 DeepSeek 按量收取。

我的 API Key 安全吗？

API Key 使用 Windows DPAPI 加密存储在本地，绑定当前用户账户，不会上传到任何第三方服务器。

支持 macOS 或 Linux 吗？

目前仅支持 Windows 10/11。后续版本计划支持 macOS 和 Linux，敬请期待。
